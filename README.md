# history2

## Пользовательские истории для приложения «Домашняя бухгалтерия»
- Регистрация: Как пользователь, я хочу зарегистрироваться, чтобы сохранять свои финансовые данные.
- Баланс: Как пользователь, я хочу видеть общий баланс, чтобы понимать своё финансовое положение.
- Доходы: Как пользователь, я хочу добавлять доходы, чтобы отслеживать поступления денег.
- Расходы: Как пользователь, я хочу записывать расходы, чтобы контролировать траты.
- Категории: Как пользователь, я хочу распределять расходы по категориям, чтобы понимать, на что уходят деньги.
- История операций: Как пользователь, я хочу просматривать и редактировать операции, чтобы контролировать финансы.
